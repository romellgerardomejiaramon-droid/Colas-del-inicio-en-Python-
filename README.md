# Colas del inicio en Python

Este programa implementa un sistema interactivo en la consola para gestionar listas simplemente ligadas en Python, permitiendo crear estructuras desde cero o cargar un ejemplo predeterminado basado en nodos con información y punteros de enlace (liga). La aplicación ofrece un menú completo que facilita realizar operaciones fundamentales como inserciones al inicio, al final o en posiciones específicas rellenando automáticamente los huecos con nodos vacíos, eliminaciones de elementos, búsquedas secuenciales y una función avanzada para hacer que dos nodos apunten a un destino común, midiendo además el tiempo exacto de ejecución de cada acción en milisegundos hasta concluir con el indicador de término FIN.

# Colas del inicio MyLinkedList

Esta robusta y moderna implementación orientada a objetos en Python trasciende la clásica terminal de comandos al ofrecer un sistema visual e interactivo construido con Tkinter para la gestión avanzada de listas ligadas bajo la biblioteca MyLinkedList, permitiendo que el usuario elija inicialmente entre cargar una estructura predeterminada de ejemplo o iniciar con un entorno completamente vacío para construir sus propios nodos desde cero mediante un panel de control gráfico que incluye botones ordenados para inserciones dinámicas al inicio, al final o en cualquier posición arbitraria con autorrellenado inteligente de espacios vacíos mediante nodos especiales VACÍO, opciones de edición directa por número de fila para cualquier nodo existente, múltiples tipos de borrados, búsquedas precisas y la compleja manipulación de punteros de dos a uno, todo ello mientras se dibuja en tiempo real la estructura de bloques y flechas que concluyen en el indicador de término FIN, complementándose con una consola de registro interna y un medidor de rendimiento de alta precisión que calcula milisegundo a milisegundo el tiempo exacto de ejecución de cada acción sin sufrir cierres inesperados gracias a un robusto blindaje en sus ventanas de entrada.
