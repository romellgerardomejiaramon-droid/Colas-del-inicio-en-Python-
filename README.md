# Colas del inicio en Python

Este programa implementa un sistema interactivo en la consola para gestionar listas simplemente ligadas en Python, permitiendo crear estructuras desde cero o cargar un ejemplo predeterminado basado en nodos con información y punteros de enlace (liga). La aplicación ofrece un menú completo que facilita realizar operaciones fundamentales como inserciones al inicio, al final o en posiciones específicas rellenando automáticamente los huecos con nodos vacíos, eliminaciones de elementos, búsquedas secuenciales y una función avanzada para hacer que dos nodos apunten a un destino común, midiendo además el tiempo exacto de ejecución de cada acción en milisegundos hasta concluir con el indicador de término FIN.

# Colas del inicio MyLinkedList

Esta versión evolucionada e interactiva desarrollada en Python eleva por completo la biblioteca MyLinkedList al trascender la clásica y estricta terminal de comandos para ofrecer una interfaz gráfica moderna construida con Tkinter, la cual dibuja de forma dinámica y en tiempo real la estructura de los nodos conectados mediante bloques visuales y flechas que culminan en el indicador de término FIN, integrando un panel de control con botones ordenados que facilitan la ejecución de operaciones complejas como el rellenado automático de espacios vacíos con nodos especiales, múltiples tipos de borrados y búsquedas precisas, implementando además la mejora solicitada donde el flujo de interacción para insertar por posición solicita primero el valor y posteriormente la fila exacta, todo ello mientras se acompaña de una consola de registro interna y un medidor de rendimiento de alta precisión que calcula milisegundo a milisegundo el tiempo de ejecución exacto de cada acción realizada por el usuario.
